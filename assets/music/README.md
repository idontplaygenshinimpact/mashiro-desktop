# 🎵 樱花庄音乐（assets/music/）

把音乐文件放进本目录即可被桌宠识别（托盘菜单「🎵 樱花庄音乐」/ 桌宠右键菜单播放）。
支持格式：`.mp3` / `.wav` / `.m4a` / `.flac` / `.ogg` / `.aac`。

## 曲名显示

默认用文件名显示（去掉扩展名）。如需显示真实曲名，创建 `music.json`：

```json
{
  "tracks": {
    "op1.mp3": "君の花を祈る（OP1）",
    "ed1.mp3": "Prime number〜君と出会える日〜（ED1）"
  }
}
```

## 功能

- 托盘/右键菜单：播放 / 停止 / 下一首 / 曲目列表 / 音量（30-100%）/ 启动自动播放
- 自动播放开关开启后，桌宠启动 6 秒自动播放音乐
- 播放状态持久化在 `data/music-state.json`（音量 / 自动播放开关）
