# 开发历史面试文档 · 5 段模板（纯提示词，零依赖）

> 用法：把【git 时间线】【opencode 会话摘录】【DSH 会话摘录】填入下方模板的【材料】位置，交给任意 LLM 生成。
> 铁律：只基于材料内容生成；材料里没有的不许编造；不确定的标注"（未在历史中确认）"。

请基于【材料】生成一份**开发历史面试文档**（Markdown），严格 5 段：

## 一、开发时间线（阶段/里程碑）

- 从 git 提交时间还原：每个阶段做了什么、为什么
- 关键转折点（如"对话主循环流式化"、"纵向拆分"、"沙箱逃逸漏洞修复"）

## 二、关键问题与决策（≥10 个）

每个：**背景 → 方案选型 → 为什么选 → 踩了什么坑 → 最终实现**
（从会话历史提取；如"为什么自研工具循环不用 LangGraph"、"为什么 ESBuild 主面板 + Vite 子项目"）

## 三、技术拷打点（≥15 个）

每个：**机制一句话 + 文件:行号（如可确认）+ 面试官追问方向**
（工具循环/权限/SSE/FSRS/SQLite WAL/FTS5/Electron 安全/worker 线程/评测方法论/MCP/插件机制……）

## 四、相关八股（≥10 个）

每个：**核心答案 + 本项目怎么用的（结合点）**
（从开发历史涉及的技术点展开；面试官可能顺带问的）

## 五、踩坑清单（≥8 个）

每个：**现象 → 根因 → 修复 → 教训**
（从会话历史提取真实踩坑；如审批超时否决/quiz 坐标/SSE 串流/沙箱逃逸/邮件 token 燃烧/关键词误命中）
