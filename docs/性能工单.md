# 性能工单（评估报告 M7/M9/M10 + 维度 5 问题）

> 背景：项目全面评估报告-2026-09 性能维度 7/10。启动路径精简（重型依赖全动态 import）是亮点，但存在数据无上限增长（Edge profiles 672MB）、渲染层 6 个无条件轮询、React 版麦克风用废弃 ScriptProcessor（Electron 43 下可能录不到声音）等问题。

---

## 二、任务

### 任务 1：数据增长上限（0.5 天）

```
① Edge profile 加容量上限（如 200MB 超限清理/提示），或按域只保留牛客（配合安全工单 S9）
② 日志按大小轮转（如 10MB × 5 份）
③ tool_results 加清理策略（保留最近 N 天/条数）
```

### 任务 2：渲染层轮询门控 + 懒加载（0.5-1 天）

```
① panel-rest.js 6 个轮询按 Tab 门控：面板隐藏/非当前 Tab 时暂停（visibilitychange + tab 切换事件）
② loadCrawlData 5s 轮询降频或仅 Crawl Tab 激活时跑
③ panel.html:884-885 react/vue bundle 改动态 import（用到才加载）
```

### 任务 3：React 版麦克风修复（0.5 天）

```
① panel-react/src/panel.jsx:210-213 ScriptProcessor → AudioWorklet（对齐 panel-rest.js:1079）
② 处理 AudioContext suspended（用户交互后 resume）
```

### 任务 4：后台读放大（0.5 天）

```
① cc-watcher.mjs:81 改 stat + 字节偏移增量读（已有偏移，只读新增段）
② rag.mjs:292 先查命中 id 再回查内容（或 SQL 层 LIMIT + 排序下推）
③ memory.mjs:247 薄弱点相似度加索引/抽样（或合并频率降为每日）
```

## 三、验收

```
① 面板切走 Tab 后：widget 服务无对应轮询请求（devtools network 验证）
② 开面板首屏不加载 react/vue bundle（切到对应面板才加载）
③ React 版语音作答在 Electron 43 下能录到声音（AudioWorklet）
④ cc-watcher 只读新增字节（日志/断点验证）
⑤ data/ 目录增长有上限（配置生效）
```
