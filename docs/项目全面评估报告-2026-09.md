## 各维度评估

### 1. 架构与设计 —— 9/10

**现状**：分层清晰且是"演进出来的"而非"画出来的"：
- **宿主 + 插件**：`widget.mjs`（HTTP :8899，139 路由）→ `lib/`（88 模块单一数据源）→ `plugins/job-hunter/`（manifest + server.mjs 聚合 12 路由域，`plugins/job-hunter/server.mjs:20-35`）→ `desktop/main.mjs`（Electron 壳）。插件加载失败隔离不拖垮宿主（`widget.mjs:83`）。
- **事件驱动内核**：`lib/events.mjs`（统一事件模型 + 表达队列）→ `lib/autonomy.mjs`（规则决策，off/notify/full 三级 + 防抖/寂静期/预算刹车）→ `lib/scenarios.mjs`（场景→技能子集）→ `lib/adapters/cc-watcher.mjs`（jsonl 字节偏移增量解析）。链路完整且每层可单测。
- **契约层**：`lib/routes/contract.mjs` 的 `withContract`（input 400 / output 500 SCHEMA_MISMATCH）+ SSE discriminated union + `kanban-api.d.ts` 74 方法 checkJs 校验。
- **并发正确性设计**：`lib/lane.mjs:12-32` 全局串行队列（注释明确论证"串行是正确 trade-off"——内存镜像单例竞态 + LLM 吞吐瓶颈）；`mail.mjs:16` IMAP 互斥、`zhenti.mjs:69-80` 抓题锁、`focus.mjs:155-181` 惰性状态流转（不依赖定时器）。

**问题**：
- `widget.mjs` 812 行仍偏大——18 组定时器 + 事件接线 + 调度器种子全在一个文件（`widget.mjs:550-789`）。
- 插件协议只有 1 个真实插件 + 1 个模板，"市场一键安装"（`POST /api/plugins/install`）实际从本地 `plugin-market.json` 读，非真实市场。

**建议**：定时任务注册抽 `lib/background-jobs.mjs`；插件市场标注"本地市场"。

### 4. 安全 —— 7.5/10

**现状**：安全基线生产级：
- **SSRF 防护教科书级**：`lib/fetch-page.mjs:56-154`——DNS 全记录解析防 rebinding（`lookup all`）、IPv4-mapped/NAT64 内嵌检测、内网域名黑名单、路由层 document 拦截；`rss.mjs:64-68` 同样校验。
- **SQL 全参数化**：node:sqlite prepared statements，无拼接注入。
- **Electron 加固**：4 个窗口 `contextIsolation:true + nodeIntegration:false + sandbox:true`，CSP 齐全（除 Vue 窗口），`window:open-file` 白名单（`main.mjs:618-632`，路径 toLowerCase 防大小写绕过）。
- **widget 服务**：绑定 127.0.0.1 + CORS 白名单 + Bearer token + 1MB body 上限。
- **判题沙箱**：worker_threads + vm 双隔离、危险方法遮蔽、敏感 env 清理、超时 terminate、resourceLimits。
- **权限分级**：`agent.mjs:107-180` deny-first 审批 + 会话级 deny 硬拦截 + 审计账本；日志只打参数键名不打值（`agent.mjs:185`、`trace.mjs:57-71`）。
- **提示注入防护全库一致**：`prompt-guard.mjs` 包裹机制在 ai/job-collect/job-match/mail/rag/rss/subagent/exec-tools/impl-*/mcp-client 全部生效，system prompt 注入 `UNTRUSTED_DECLARATION`。
- **win-toast 安全**：base64 + `-EncodedCommand`（`win-toast.mjs:11-28`），无注入面。

**问题**：
- **严重：判题沙箱 `process.getBuiltinModule` 逃逸缺口**（`sandbox-worker.mjs:13-16`）：只遮蔽 `exit/kill/abort/disconnect/binding/dlopen/chdir`，但 Node ≥22.3 的 `process.getBuiltinModule('fs')` 未遮蔽（实测 Node 22 可用）。不可信判题代码可 `Promise.constructor("return process")()` 拿到 worker 的 process（注释已承认 worker 与主进程同进程），再 `getBuiltinModule('fs').readFileSync(...)` 读宿主任意文件（含 API key）或 `getBuiltinModule('child_process')` 执行命令。
- **严重：判题断言可被用户代码伪造**（`sandbox-worker.mjs:48-52, 63-70`）：`__mashiroAssert9f3a__` 注入 vm 全局，且 userCode 与 testCode 拼进同一 async IIFE 作用域——用户代码可直接 `__mashiroAssert9f3a__(true, "fake")` 伪造通过，不解决也能 PASS。
- **严重：无 `setWindowOpenHandler`/`will-navigate` + 全部 IPC handler 无 `e.sender` 校验**（`desktop/main.mjs` 全文 grep 0 命中）：渲染层大量 `target="_blank"` 外链（`panel-rest.js:306,403,1372`、`panel-jobs.js:197,279,487,488`、`panel-study.js:2046`），Electron 默认在新 BrowserWindow 打开外链并**继承 opener 的 webPreferences（含 preload.js）**——被攻破的外部站点（牛客/BOSS 等）会拿到 `window.kanban` 全量 IPC 桥，可调 openFile/restartApp/quit/speak/music。
- **严重：`.env.bak` 明文真实 API key**（验证：`DEEPSEEK_API_KEY=sk-UW7x...` 完整明文）——已 gitignore 不入库，但本地明文备份是泄露面，key 应视为已暴露。
- **中等：Edge 登录态全量复制**：`lib/edge-session.mjs:47-113` 把 Edge Cookies 库**连同 Local State（cookie 加密 key）**复制到 `data/edge-user-profile`（532MB）——所有网站登录态可解密地躺在项目目录。
- **中等：MCP 自环 `permission:"auto"` 绕过审批**：`data/mcp-servers.json:8` + `lib/mcp-client.mjs:107-111`——外部 agent 经 `mcp__mashiro__solve_question`（写文件 + 2.4 万 token）无需确认，与内置 confirm 不一致。
- **中等：toolFetchPage SSRF 重定向未复检**（`lib/tools/impl-search.mjs:149-153`）：`fetch(raw, { redirect: "follow" })` 跟随重定向后不再校验——公网 URL 可 302 到 `http://127.0.0.1:8899` 或内网服务（此路径用 Node fetch 直连，不走 fetch-page 的 Playwright 守卫）。
- **中等：Vue 复习卡独立窗口无 CSP**（`panel-vue-review/dist/index.html`），与其他窗口不一致。
- **中等：死代码 `_toastFallback` 存在 PowerShell 注入**（`widget.mjs:205-214`）——无调用方不可达，应删除。
- **中等：skill 工具默认 auto**（`skills.mjs:127` `t.permission === "confirm" ? "confirm" : "auto"`）——与 `getSkillPermission:160` 的 fail-closed 注释不一致（当前 10 个技能均为作者自写，风险有限）。
- **轻微：3 个传递依赖漏洞**（`npm audit` 实测）：`fast-uri@3.1.5`（high，经 MCP SDK→ajv）、`@xmldom/xmldom@0.8.13`（moderate，经 mammoth）、`qs@6.15.3`（moderate，经 express）——均可 `npm audit fix`。
- **轻微**：`oj.mjs:246-271` 内部抓取未复用 `assertPublicUrl`（HTTP 层已挡）；`chrome-cookies.mjs:56` 解密失败静默无日志。

**建议**：优先修判题沙箱两处逃逸（遮蔽 `getBuiltinModule`/`_linkedBinding` + 断言闭包只作参数传给 testCode 不注入全局）+ 补测试；`setWindowOpenHandler` 一律 `shell.openExternal` 或 deny + IPC sender 校验；删 `.env.bak` 并轮换 key；edge-session 只复制牛客域 cookie；重定向后复检 finalUrl；Vue 窗口补 CSP。
