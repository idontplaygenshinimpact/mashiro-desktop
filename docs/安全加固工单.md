## 二、任务

### 任务 1：删 .env.bak + 轮换 key（5 分钟，立即做）

```
① 删除 .env.bak（含明文 DEEPSEEK_API_KEY）
② 到 DeepSeek 平台重新生成 key，更新 .env
③ 确认 .gitignore 已含 .env.bak（防再犯）
```

### 任务 2：判题沙箱两处逃逸（0.5 天）

```
① sandbox-worker.mjs:13-16 遮蔽 process.getBuiltinModule / _linkedBinding
   （与 exit/kill/abort 同列表遮蔽；或改独立子进程方案）
② 断言闭包改为只作参数传入 testCode 作用域：
   userCode 与 testCode 不再拼进同一 async IIFE——
   __mashiroAssert9f3a__ 从 vm 全局移除，改为 testCode 参数接收
③ 补测试（见测试工单任务 2）：getBuiltinModule 逃逸路径 + 断言伪造路径
```

### 任务 3：Electron 窗口安全面（0.5-1 天）

```
① main.mjs 所有 BrowserWindow 加 setWindowOpenHandler：
   一律 shell.openExternal（外链走系统浏览器）或 deny
② 全部 IPC handler 加 e.sender 校验（校验 sender 是已知窗口 webContents id）
③ Vue 复习卡窗口补 CSP meta（与其他窗口一致）
```

### 任务 4：其余安全项（0.5 天）

```
① edge-session.mjs：只复制牛客域 cookie（或加密副本），不再整库复制 Local State
② mcp-servers.json 自环配置：写文件类工具设 permission:"confirm"
③ impl-search.mjs:149-153：重定向后复检 finalUrl（或 redirect:"manual" 手动跟随校验）
④ widget.mjs:205-214 删除 _toastFallback 死代码

⑥ skills.mjs:127 默认改 confirm（与 getSkillPermission fail-closed 注释一致）

```
