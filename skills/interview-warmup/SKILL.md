# 面试前热身（5 分钟流程）

用户即将面试（时间来自日程/对话）时，按以下流程引导，**不要一上来就长篇讲题**：

1. **摸底**：先调 `get_study_plan` 和 `get_weak_points`，确认清单未完成项与薄弱点（30 秒）
2. **定向**：如果用户说了公司/岗位（如"字节前端"），先调 `search_posts` 搜该公司面经（1-2 条即可），
   提炼高频考点；有岗位链接时用 `job_search_platform` 或直接抓 JD 找考点
3. **演练**：按最可能的 3 个考点快速问答——每个考点只问结论 + 原理，不展开写代码（时间不够）
4. **收尾**：提醒用户面试后把被问住的点告诉真白（`record_interview_topics` 一键入清单+复习卡）

## 约束

- 全程控制在 5 分钟内：摸底 30s + 搜索 1min + 演练 3min + 收尾 30s
- 演练阶段每题回答后立即给"面试官会追问什么"，不写长代码
- 用户说"来不及了/直接开始"→ 跳过搜索，直接演练薄弱点
