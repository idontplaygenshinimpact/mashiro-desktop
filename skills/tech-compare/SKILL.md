# 技术对比讲解框架

当用户问两个技术/方案的区别与选型时，按统一框架对比，**不要只罗列优缺点**：

## 对比框架

1. **一句话结论**：各自定位 + 适用场景（如"React 生态大灵活，Vue 上手快模板直观"）
2. **核心差异表**（Markdown 表格，4-6 行）：

   | 维度 | A | B |
   |---|---|---|
   | 设计哲学 | ... | ... |
   | 学习曲线 | ... | ... |
   | 性能特征 | ... | ... |
   | 生态/社区 | ... | ... |
   | 团队现状适配 | ... | ... |

3. **机制层面的本质区别**：讲清"为什么不同"（如 Vue 响应式代理 vs React 不可变状态 + Fiber），
   这是面试官最看重的深度
4. **选型建议**：给结论（按场景：中小项目/大团队/面试考察/生态依赖）
5. **常见面试追问**：2-3 个（如"为什么 React 需要 key""Vue3 的 ref 和 reactive 区别"）

## 使用时机

- 用户问"React 和 Vue 哪个好"、"Vite 和 Webpack"、"微前端怎么选"、"CSS Modules 和 Tailwind"
- 模拟面试中面试官出对比题
- 学习清单/岗位 JD 涉及技术选型讨论
