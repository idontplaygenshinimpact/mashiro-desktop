# interview-prep：项目面试准备

## 何时使用

用户说以下任一触发：
- "准备 XX 项目的面试 / 生成 XX 项目的面试准备文档"
- "这个项目面试官会怎么拷打 / 帮我准备项目应答"
- "项目涉及哪些八股 / 面试前过一遍项目"

## 使用流程

1. **确认项目**：调 `skill__interview_prep__prepare_project_interview`（project=项目名——personal_projects 配置中的 name）
2. **生成文档**：工具读项目全部核心源码（排除测试/配置——核心目录优先）→ subagent 串行分析（源码要点 + 八股）→ 八股提取（专门 subagent）→ LLM 生成完整面试准备文档 → 存档 `output/interview-prep/项目·xxx-面试准备.md`
3. **查看/背诵**：文档含项目概览 + 源码要点 + 全部八股（原理/项目用法/面试应答/追问——详细可背）+ 全覆盖拷打问答（每个文件/知识点/决策都被拷打——完整答案可背）
4. **重新生成**：用户说"重新生成" → force=true（重新读源码生成）

## 纪律

- **只基于真实源码**——档案/源码里没有的不许编（防幻觉技术栈/功能/文件名）
- **八股准确**——原理/对比/追问不幻觉
- **覆盖核心业务**——不只是配置文件——核心逻辑/核心模块必须覆盖
- **技术栈自适应**——项目用什么就提取什么八股（不套用固定列表）
- **详细可背**——每个知识点/问答都是完整表述（口语化——背下来直接答——不是笔记/提纲）
- **拷打全覆盖**——项目涉及的全部内容都被拷打（每个文件/知识点/决策——数量不限）
