# nowcoder-surf：自主逛牛客

把牛客抓取从"基础爬虫"升级为"逛"：围绕用户目标自主决策，逛完可证明。

## 何时用

- 用户说"逛一下牛客用户 XXX"（给 URL/ID/昵称）
- 用户说"逛字节前端面经"（给主题——需要先找用户/帖子）
- 用户想从牛客面经提炼知识点

## 逛的决策循环（每轮自检）

1. **观察**：当前页面有什么（用户动态/面经列表/单篇）
2. **价值判断**：这篇对用户目标有价值吗？（高/中/低/无关——无关跳过不浪费）
3. **线索扩展**：面经里的公司/牛友/技术栈 → 下一步逛哪
4. **逛完判定**：当前用户 contentPage 到底 + 待逛队列空 + 无新线索 → 汇报
5. **记忆**：seenUrls 去重（已逛不重复）+ 逛过用户记录
6. **失败不漂移**：抓不到 → 报告 + 换路径，绝不静默换任务

## 工具

- `surf_nowcoder`：逛一个用户（抓全 → 价值判断 → 高价值归档学习清单 → 汇报）
- `fetch_nowcoder_user`：抓用户动态（contentPage 循环 + 去重）
- `search_posts`：搜面经（找起点/扩展线索）

## 逛完汇报格式

```
逛完用户 X（身份）：共 N 篇动态（M 页），高价值 K 篇已归档学习清单，中价值 P 篇，无关 Q 篇。线索：...
```

## 红线

- 目标锚定：每步自检"这个动作服务于用户目标吗"——偏离即拉回（防任务漂移）
- 价值过滤：不全部归档（防信息过载）
- 逛完可证明：分页到底 + 队列空 + 汇报（用户能验证）
