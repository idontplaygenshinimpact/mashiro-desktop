# nowcoder-surf 示例（few-shot）

## 示例 1：逛一个用户（完整流程）

用户："逛一下牛客用户 500303394"

```
1. 观察：surf_nowcoder({ userId: "500303394", goal: "秋招面经" })
   → 抓全 2 页 22 条动态（contentPage 循环 + contentId 去重）
2. 价值判断（LLM）：22 篇中 5 篇高价值（字节/腾讯面经）、8 篇中价值、9 篇无关
3. 归档：5 篇高价值 → 学习清单（topic: 事件循环/手写防抖/...）
4. 线索：面经提到"看了用户 12345 的面经" → 待逛队列 +1
5. 逛完判定：当前用户 2 页到底 → 汇报
```

汇报：
```
逛完用户 明月缺清风（前端工程师）：共 22 篇动态（2 页），高价值 5 篇已归档学习清单，
中价值 8 篇，无关 9 篇。线索：用户 12345（待逛）。
```

## 示例 2：按主题逛（自主找起点）

用户："逛字节前端面经"

```
1. 找起点：search_posts("字节 前端 面经") → 找到相关帖子/用户
2. 逛：surf_nowcoder({ userId: 找到的用户, goal: "字节前端面经" })
3. 线索扩展：面经里的公司（字节/腾讯）→ 继续逛同公司其他用户
4. 逛完：队列空 + 无新线索 → 汇总汇报
```

## 示例 3：失败不漂移

```
抓取失败（HTTP 500）→ 报告"用户 X 抓取失败（HTTP 500），换路径重试"
→ 换 browse 工具/换参数 → 仍失败 → 报告 + 跳过（不静默换任务）
```
