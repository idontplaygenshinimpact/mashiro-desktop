## 一、浅拷贝与深拷贝的区别

### 1. 浅拷贝
只拷贝对象的第一层属性，如果属性是基本类型，拷贝的是值；如果属性是引用类型（对象、数组等），拷贝的是**引用地址**。  
**结果**：新对象和原对象的嵌套对象指向同一个内存地址，修改嵌套对象会影响原对象。

常见浅拷贝实现：
- `Object.assign({}, target)`
- 展开运算符 `{...target}`
- 数组的 `slice()` / `concat()`

### 2. 深拷贝
递归拷贝对象的所有层级，目标对象的每一层都是**全新的对象**，与原对象完全独立。  
**结果**：修改新对象的任何层级，都不会影响原对象。

常见“偷懒”方式：  
```javascript
JSON.parse(JSON.stringify(obj))
```
但这种方式有严重缺陷：
- 函数、`undefined`、`Symbol` 会被忽略
- `Date` 会变成字符串
- `RegExp` 会变成空对象 `{}`
- 循环引用会直接报错

所以手写一个完整的 `deepClone` 是很有必要的。

## 二、手写 deepClone

我们需要考虑的数据类型：基本类型、普通对象、数组、`Date`，以及循环引用。  
下面给出一个可扩展的版本。

### 核心思路
1. 基本类型直接返回。
2. 遇到 `Date` / `RegExp` 等特殊对象，创建对应的新实例。
3. 遇到 `Map` / `Set` 等，递归克隆内部元素。
4. 处理循环引用：用 `WeakMap` 记录“原对象 → 克隆对象”的映射，如果已经克隆过，直接返回之前克隆的结果。
5. 最后处理普通对象和数组，递归拷贝每个属性。

### 代码实现

```javascript
function deepClone(obj, hash = new WeakMap()) {
  // 基本类型或函数：直接返回（函数通常保持引用即可）
  if (obj === null || typeof obj !== 'object') return obj;

  // 处理 Date
  if (obj instanceof Date) return new Date(obj);

  // 处理 RegExp
  if (obj instanceof RegExp) return new RegExp(obj.source, obj.flags);

  // 处理 Map
  if (obj instanceof Map) {
    const cloneMap = new Map();
    hash.set(obj, cloneMap);
    obj.forEach((value, key) => {
      cloneMap.set(deepClone(key, hash), deepClone(value, hash));
    });
    return cloneMap;
  }

  // 处理 Set
  if (obj instanceof Set) {
    const cloneSet = new Set();
    hash.set(obj, cloneSet);
    obj.forEach(value => {
      cloneSet.add(deepClone(value, hash));
    });
    return cloneSet;
  }

  // 如果已经克隆过，直接返回（解决循环引用）
  if (hash.has(obj)) return hash.get(obj);

  // 处理数组和普通对象（构造函数可扩展）
  const clone = Array.isArray(obj) ? [] : {};

  // 先把当前对象存入 hash，再递归克隆属性
  hash.set(obj, clone);

  // 拷贝所有自身的可枚举属性（包含 Symbol 键）
  const keys = [
    ...Object.keys(obj),               // 字符串键
    ...Object.getOwnPropertySymbols(obj) // Symbol 键
  ];
  for (const key of keys) {
    clone[key] = deepClone(obj[key], hash);
  }

  return clone;
}
```

### 测试用例

```javascript
const original = {
  num: 0,
  str: 'hello',
  bool: true,
  obj: { name: 'Jack', hobbies: ['coding', 'gaming'] },
  arr: [1, 2, { x: 3 }],
  date: new Date(),
  reg: /\d+/g,
  map: new Map([['key', 'value']]),
  set: new Set([1, 2, 3]),
  sym: Symbol('test'),
};

// 循环引用
original.self = original;

const cloned = deepClone(original);

console.log(cloned === original);            // false
console.log(cloned.obj === original.obj);    // false
console.log(cloned.arr[2] === original.arr[2]); // false
console.log(cloned.self === cloned);         // true，循环引用正确处理
```

## 三、面试官常追问的问题

### Q1：为什么用 `WeakMap` 而不是 `Map`？
因为 `WeakMap` 是弱引用，不会阻止垃圾回收。当原对象被回收时，与之对应的 `WeakMap` 记录也能被自动回收，避免内存泄漏，更适合这类缓存场景。

### Q2：`Date` 为什么要用 `new Date(obj)`？
`Date` 实例直接 `typeof` 是 `object`，但它的内部状态是时间戳。直接赋值引用的话就是浅拷贝。通过 `new Date(obj)` 会调用 `Date` 构造函数，把原日期的时间戳作为参数，生成一个独立的日期对象。

### Q3：如何拷贝 `Symbol` 作为属性键？
`Object.keys()` 只能拿到字符串键，拿不到 Symbol 键。我们需要 `Object.getOwnPropertySymbols(obj)` 来获取 Symbol 属性，或者用 `Reflect.ownKeys(obj)` 一次性拿到所有键（包括不可枚举的）。

### Q4：如果只拷贝自身可枚举属性，应该怎么写？
上面代码已经用了 `Object.keys` + `Object.getOwnPropertySymbols`，只处理自身可枚举的属性，避免循环遍历原型的属性。如果希望更彻底地拷贝，可以加原型保留：

```javascript
const clone = Array.isArray(obj) ? [] : Object.create(Object.getPrototypeOf(obj));
```

### Q5：为什么没有处理函数？
函数通常没有运行时状态，深拷贝函数一般没有意义，保持引用即可。上面的代码遇到函数会直接返回原函数（因为 `typeof` 不是 `object`）。
