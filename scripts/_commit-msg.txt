fix: 复习卡四个体验问题——切页保状态 / 跳过切题 / 默答引导 / 解析明确

【用户反馈】
1. 切换页面后复习选择题已选状态丢失
   → 根因：切回复习 Tab 触发 loadReview → loadCardQuiz 重载，quizState.chosen 被清空
   → 修复：同卡跳过重载（保留 chosen），renderQuiz 按已选状态恢复 picked
2. 无法切换题目
   → 新增「⏭ 跳过」按钮：不评分、放回队列尾部稍后复习（FSRS 不动）
3. "类似简答的标题"意义不明
   → 根因：rc-question 是默答题干但无引导，与选择题/评级混在一起
   → 修复：题干上方加三步引导「先默答→显示答案核对→选择题+评级」
4. 选择题解析不明确
   → 答错明确显示「正确答案：B. xxx」+ 解析独立成块（背景+左边框）；
     解析样式强化（quiz-fb 卡片化）

测试 +2（跳过不评级放回队尾 / 切 Tab 已选保留），全量 645/645。
