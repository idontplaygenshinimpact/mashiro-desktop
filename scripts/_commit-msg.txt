fix: 模拟面试「看不到问题」真凶落网——残留会话阻塞 + 前端自愈

【真实链路复现（curl 真实 widget 服务）】
用户报「还是没有问题显示」→ 直接调 /api/interview/start 得到：
  error: 已有一场面试进行中，先结束（end_interview）或继续回答
根因：上一场面试未正常结束（关面板/杀进程/中途退出）→ 会话留在 widget 内存
（常驻进程不清）→ 之后每次点「开始模拟面试」后端都拒绝 → 前端 alert 后 return
→ 问题永不显示。之前所有「看不到问题」大概率都是这个（jsdom 测试只 mock 成功路径，
错误路径零覆盖——这是测试盲区）。

【修复】
- 前端 startIvSession 自愈：start 报「进行中」→ 自动 invEnd 收尾旧会话（生成复盘）
  → 自动重试 start → 正常显示问题，用户无感；收尾也失败则明确提示可重试
- 抽 showInterviewUi 公共函数（正常路径与自愈重试共用，避免逻辑分叉）

【测试补盲区（+2 用例）】
- 残留会话自愈：start 拒绝 → invEnd 恰好 1 次 → 重试 start → 问题最终显示、无 alert
- 自愈失败：invEnd 也挂 → 明确 alert + 按钮恢复可重试
